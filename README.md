# deribit-mcp

MCP (Model Context Protocol) server for the Deribit cryptocurrency derivatives
trading platform.

This crate is a **placeholder** reserving the name on [crates.io](https://crates.io).
A full implementation is in development and will land in a future release.

## Companion crates

- [`deribit-base`](https://crates.io/crates/deribit-base) — common structs, traits, and logic
- [`deribit-http`](https://crates.io/crates/deribit-http) — HTTP REST API client
- [`deribit-websocket`](https://crates.io/crates/deribit-websocket) — WebSocket client
- [`deribit-fix`](https://crates.io/crates/deribit-fix) — FIX 4.4 client
